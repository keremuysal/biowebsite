# Personal Link Page / Kişisel Bağlantı Sayfası

## EN English

### 📖 About The Project
This is a minimalist, responsive, and dark-themed personal landing page designed to act as a central hub for all my social media links, portfolio, and contact information. It serves as a custom, lightweight alternative to services like Linktree.

**Rebuilt in 2025**, focusing on performance, clean aesthetics, and smooth CSS animations.

### ✨ Features
* **Responsive Design:** Looks great on mobile, tablet, and desktop.
* **Dark Mode Aesthetic:** Uses a comfortable color palette (`#121212` background) suitable for all screens.
* **Animations:** Smooth fade-in entry animation and hover effects on buttons.
* **Lightweight:** Built with pure HTML5 and CSS3. No external frameworks or JavaScript libraries required.
* **Fast Loading:** Optimized for speed.

### 🛠️ Built With
* **HTML5**
* **CSS3** (CSS Variables, Flexbox, Keyframe Animations)
* **Google Fonts** (Poppins)

### 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/keremuysal/biowebsite.git
    ```
2.  **Customize the content:**
    * Open `index.html` to update the links (`href`) and text.
    * Place your profile picture in an `img` folder and name it `portre.webp` (or update the `src` in HTML).
3.  **Run locally:**
    Simply open the `index.html` file in your web browser.

## 🇹🇷 Türkçe

### 📖 Proje Hakkında
Bu proje, tüm sosyal medya hesaplarımı, portföyümü ve iletişim bilgilerimi tek bir yerde toplamak amacıyla tasarlanmış; minimalist, mobil uyumlu ve karanlık temalı kişisel bir açılış sayfasıdır. Linktree gibi servislerin yerine kullanılabilecek, tamamen özelleştirilebilir ve hafif bir alternatiftir.

**2025 yılında**, performans, temiz görünüm ve akıcı CSS animasyonlarına odaklanılarak yeniden inşa edilmiştir.

### ✨ Özellikler
* **Mobil Uyumlu (Responsive):** Telefon, tablet ve masaüstü cihazlarda kusursuz görünür.
* **Karanlık Tema:** Göz yormayan renk paleti (`#121212` arka plan) kullanılmıştır.
* **Animasyonlar:** Sayfa açılışında yumuşak bir belirme (fade-in) efekti ve butonlarda etkileşimli "hover" efektleri bulunur.
* **Hafif Yapı:** Saf HTML5 ve CSS3 ile yazılmıştır. Harici bir framework veya JavaScript kütüphanesi gerektirmez.
* **Hızlı Yükleme:** Performans için optimize edilmiştir.

### 🛠️ Kullanılan Teknolojiler
* **HTML5**
* **CSS3** (CSS Değişkenleri, Flexbox, Keyframe Animasyonları)
* **Google Fonts** (Poppins)

### 🚀 Kurulum ve Kullanım

1.  **Repoyu klonlayın:**
    ```bash
    git clone https://github.com/keremuysal/biowebsite.git
    ```
2.  **İçeriği düzenleyin:**
    * Bağlantıları (`href`) ve metinleri değiştirmek için `index.html` dosyasını açın.
    * Profil fotoğrafınızı `img` klasörü içine `portre.webp` adıyla ekleyin (veya HTML içindeki dosya yolunu güncelleyin).
3.  **Çalıştırın:**
    `index.html` dosyasına çift tıklayarak tarayıcınızda açmanız yeterlidir.
